QUEEN BURGER — خطوات إكمال الربط والنشر (مجانية ضمن حدود الخطط المجانية)

الموجود في هذه الحزمة:
- index.html: موقع الزبائن. سلة، بحث، تصنيفات، إرسال WhatsApp، ومحاولة حفظ الطلب في Supabase عند ضبط الإعدادات.
- admin.html: لوحة دخول المدير وعرض الطلبات وتغيير حالتها.
- supabase_schema.sql: جداول وقواعد حماية قاعدة البيانات.
- README.txt: هذا الدليل.

أولاً: إنشاء قاعدة البيانات
1) افتح https://supabase.com وأنشئ حساباً ومشروعاً جديداً بالخطة المجانية.
2) من Project Settings > API انسخ Project URL والمفتاح العام anon/publishable.
3) افتح index.html وابحث عن:
   SUPABASE_URL = "ضع_رابط_مشروعك_هنا"
   SUPABASE_ANON_KEY = "ضع_المفتاح_العام_هنا"
   واستبدل النصين بالقيم الحقيقية.
4) افتح admin.html واستبدل القيمتين نفسيهما هناك أيضاً.
5) من SQL Editor في Supabase نفّذ محتوى supabase_schema.sql.

ثانياً: إنشاء حساب المدير
1) من Authentication > Users أنشئ حساباً للمالك بالبريد وكلمة مرور قوية.
2) انسخ UUID الخاص بالحساب.
3) في SQL Editor نفّذ:
   insert into public.admin_users (user_id) values ('UUID-HERE');
   واستبدل UUID-HERE بمعرّف حساب المالك.
4) افتح /admin.html وسجّل الدخول بالبريد وكلمة المرور.

ثالثاً: النشر
الخيار المقترح: Cloudflare Pages أو GitHub Pages ضمن الخطة المجانية.
- ارفع الملفات الثلاثة إلى مستودع GitHub جديد (index.html يجب أن يكون في الجذر).
- اربط المستودع بـ Cloudflare Pages، واختر إعدادات نشر موقع ثابت دون build command، ومجلد الإخراج الجذر / .
- بعد النشر ستحصل على عنوان مجاني مثل project.pages.dev.
- جرّب إرسال طلب تجريبي وتأكد من ظهوره في لوحة الإدارة.

ملاحظات مهمة:
- لا تضع service_role key في index.html أو admin.html أبداً.
- لا تشارك كلمة مرور المدير.
- طلب WhatsApp لا يُرسل تلقائياً؛ الزبون يضغط إرسال داخل تطبيق WhatsApp.
- إذا تعذّر حفظ الطلب في قاعدة البيانات، ستظهر رسالة وسيبقى خيار WhatsApp كمسار احتياطي.
- الخطط المجانية لها حدود وقد تتغير، لذلك لا أستطيع ضمان المجانية إلى الأبد.
- قائمة الطعام الحالية بُنيت من المعلومات المقروءة من صورة المنيو، ويجب تدقيق كل صنف وسعر قبل اعتمادها رسمياً.
- صور الأطعمة توضيحية من Unsplash وليست صوراً مؤكدة لأطباق المطعم.
